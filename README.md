# Alsoul

> **A companion with a world, not a chatbot with tools.**

Alsoul is a persistent personal companion designed around durable personhood, evidence-grounded memory, explicit epistemic boundaries, world access, trustworthy authority, and continuity across models, threads, surfaces, and future embodiments.

## Current phase

**F2 — Architecture Convergence**

The architecture has reached sufficient convergence to close the exact ownership, lifecycle, recovery, memory/evidence, epistemic, and world-interface contracts before implementation begins.

## Repository documentation policy

This repository contains **Alsoul-native architecture, decisions, contracts, and implementation**. Public documentation is written in normalized project terminology and does not include comparative references to external projects or products. Research provenance and comparative study material remain outside the repository.

## Build direction

```text
Person
  ↓
Historical Truth
  ↓
Evidence + Claims
  ↓
Epistemic Policy
  ↓
World Observation
  ↓
Interpretation
```

The first implementation remains deliberately narrow: persistent Person + evidence-aware memory + minimal PersonModel + read-only fresh-world investigation. Broad delegation, personal connectors, write authority, voice/embodiment, commitments, and procedural learning remain later gates.

Postponed work is not an implicit backlog. It is activated only when its recorded product forcing function exists.
