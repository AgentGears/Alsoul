# Alsoul

> **A companion with a world, not a chatbot with tools.**

Alsoul is a persistent personal companion designed around durable personhood, evidence-grounded memory, explicit epistemic boundaries, world access, trustworthy authority, and continuity across models, threads, surfaces, and future embodiments.

## Current phase

**F2 — Architecture Convergence**

Research has reached pattern saturation: new project studies now primarily challenge or refine existing architecture rather than create new foundational abstractions. The immediate goal is to close the exact ownership, lifecycle, recovery, memory/evidence, epistemic, and world-interface contracts before implementation begins.

## Build direction

```text
Person
  ↓
Historical Truth
  ↓
Evidence + Claims
  ↓
Epistemic Policy
  ↓
World Observation
  ↓
Interpretation
```

The first implementation remains deliberately narrow: persistent Person + evidence-aware memory + minimal PersonModel + read-only fresh-world investigation. Broad agents, personal connectors, write authority, voice/embodiment, commitments, and procedural learning remain later gates.
